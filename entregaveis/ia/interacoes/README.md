# Interações com IA

O professor pede as interações com as IAs usadas. Cada integrante anexa aqui as **suas** conversas reais.
Não resuma de memória nem reescreva a conversa: exporte ou compartilhe a original.

## Formato

Um arquivo por integrante, por ferramenta e por dia (ou sessão):

```
<integrante>-<ferramenta>-<AAAA-MM-DD>.md
```

Exemplos: `lavinia-chatgpt-2026-10-02.md`, `caio-copilot-2026-10-15.md`.

Cada arquivo tem:

1. **Integrante, ferramenta e data.**
2. **Link compartilhado da conversa**, quando a ferramenta oferece (ChatGPT, Claude.ai e Gemini têm
   "compartilhar"). Confira se o link abre numa janela anônima.
3. **Ou a exportação da conversa**, colada no arquivo ou anexada ao lado (`.md`, `.txt`, `.pdf` ou `.json`),
   quando não houver link (por exemplo, o Copilot no editor ou o Claude Code no terminal).
4. **O que foi pedido e o que foi aproveitado**, em 2 a 5 linhas, com os commits ou arquivos afetados.
